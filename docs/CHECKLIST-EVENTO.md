# Checklist pre-charla — SpaceX Santa Cruz

Marca cada ítem antes de subir al escenario.

## Contenido

- [ ] Bio en “Quién soy” revisada (¿agregar foto o handle de X?)
- [ ] Fecha exacta del evento confirmada (hoy la página no fuerza una fecha inventada)
- [ ] Scope limpio: cero menciones a Tangem / crypto en esta landing
- [ ] Ortografía y tono “tú” leídos en voz alta una vez

## Repo y hosting

- [ ] Repo GitHub creado (nombre sugerido: `grokbot-speaker-landing`)
- [ ] ZIP o carpeta subida / `git push` hecho
- [ ] URL pública lista (GitHub Pages, Netlify, Cloudflare Pages, o link directo al `index.html`)
- [ ] URL anotada para proyectar / compartir con la audiencia

## Demo en vivo

- [ ] Abrir `index.html` localmente en el laptop de backup (doble clic / File → Open)
- [ ] Probar scroll de secciones en móvil (nav sticky)
- [ ] Tener `docs/PROCESO.md` a mano como guion del making-of
- [ ] Tener el ZIP o el folder listo por si falla la red

## Escenario

- [ ] Proyector / HDMI / airplay probado

- [ ] Modo oscuro del SO coherente con el tema de la página
